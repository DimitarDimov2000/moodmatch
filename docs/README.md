# Documentation Guide

This folder contains both current reference docs and historical planning/checkpoint material.

## Current Reference Docs

- `local-setup.md`: local development, testing, and demo QA
- `architecture.md`: current high-level system overview
- `api-contract.md`: implemented REST API contract
- `scoring-and-matching.md`: deterministic scoring/readiness behavior
- `external-media-sources.md`: provider coverage, fallback rules, and mapping notes
- `testing-strategy.md`: test scope and QA strategy
- `auth-provider-decision.md`: current auth direction and rationale
- `data-model.md`: persistence and migration-aligned data model
- `future-roadmap.md`: remaining work intentionally outside the final prototype scope

## Historical Or Planning Docs

Some docs are intentionally kept for project history, checkpoint traceability, or planning context. They may contain older package names, earlier roadmaps, or assumptions that no longer match the final prototype exactly.

Examples include:

- `checkpoint-phase-19.md`
- `finalization-plan.md`
- `auth-implementation-plan.md`
- other `*-plan.md`, `checkpoint-*`, or exploratory auth/provider notes

When documentation conflicts, prefer the current reference docs listed above and the repository root `README.md`.
